01 / ROLE TYPES

行当与角色

行当是戏曲舞台塑造人物的角色分类系统。国家级非遗项目资料列出的越剧主要脚色行当有六类；每一类还可能继续细分。

SIX MAIN ROLE TYPES

小生男性角色类别
老生男性角色类别
小丑喜剧性脚色类别
老旦年长女性角色类别
大面传统脚色类别

小旦可细分为悲旦、花旦、闺门旦、花衫、正旦、武旦；小生可细分为书生、穷生、官生、武生。不同剧目和演出传统中的具体归类，应以相关剧种资料与实际表演为准。

观看提示：不要只凭服装或年龄判断行当。人物身份、性格、唱念做舞的处理，以及剧目传统都参与角色塑造。
02 / COSTUME

服装与色彩

越剧服装的舞台审美经历了改良与发展。非遗项目资料指出，越剧服装在继承传统的基础上借鉴古代仕女画，整体款式趋向清新自然，色彩与质料较为柔和淡雅。

衣纹
FORM / 形制

从人物身份看服装

观察衣身轮廓、衣长、袖型、领口、腰身与层次。服装不仅营造时代氛围，也帮助观众理解人物身份、处境和行动需要。具体款式会随剧目、人物设定与制作版本变化。

设色
COLOR / 色彩

从整体关系看配色

留意主色、辅助色与点缀色之间的关系，以及服装与舞台布景、灯光、人物气质的协调。不要把某一种颜色简单固定为某一种性格或身份。

示意色板：用于练习观察色彩关系，并非越剧服装的固定规范。

服装观察练习：选一张演出剧照，先记录主色，再观察衣领、袖口、腰带、纹样与配饰。最后思考这些设计如何帮助观众识别人物。
03 / HEADWEAR

盔帽与头饰

头部造型是人物整体形象的重要部分。相关越剧盔帽研究以嵊州越剧博物馆藏品为样本，从形制、纹样、色彩三个维度展开分析。

01 / 盔

盔

传统戏曲盔帽类别之一。观察时可留意整体轮廓、顶部结构、装饰位置与佩戴方式。

02 / 冠

冠

传统盔帽类别之一。可从形制、装饰纹样及其与人物身份设定的关系入手认识。

03 / 帽

帽

传统盔帽类别之一。不同角色与剧目会采用不同设计，需结合具体舞台图像辨认。

04 / 巾

巾

传统盔帽类别之一。可观察包裹方式、结饰和轮廓如何影响人物头部比例。

PATTERN / 纹样

纹样的疏密与寓意

观察装饰图案的布局、虚实、重复和留白。不要在缺少出处时擅自断定某一纹样的固定寓意。

CRAFT / 工艺

形制与制作

关注支撑结构、材料、装饰层次与佩戴稳定性。博物馆实物比单张舞台照片更适合研究结构细节。

研究提示：盔、冠、帽、巾是研究文章采用的分类框架。舞台实践中的具体名称、使用范围与历史形制仍应以藏品说明和专业文献为准。
04 / MAKEUP

妆容与造型

中国非遗网对越剧舞台审美的概述指出，越剧化妆吸收话剧、电影的方法，倾向贴近自然、清新淡雅，不以夸张浓艳为主要追求。

FACE / 面部

自然与舞台可读性

观察底妆、眉眼、唇色与舞台灯光下的整体效果。妆容既需要呈现人物气质，也需要适应剧场观看距离与舞台照明。

HAIR / 发式

发式与头饰的整体关系

发式、头饰、脸型与服装领口共同构成角色造型。分析时可以先看整体轮廓，再看发髻、鬓角、饰件的细节。

注意：不同年代、院团、人物身份与导演审美会带来造型差异。这里介绍的是越剧整体审美倾向，不是所有角色必须遵守的统一妆容模板。
05 / MOVEMENT

身段与舞台

越剧表演既吸收话剧、电影的表现方法，也学习昆曲、京剧的舞蹈身段和表演程式，形成写实与写意相结合的舞台表达。

眼神

观察视线方向与停留，理解人物正在关注谁、回避什么。

手势

留意手部动作与人物情绪、交流对象和情境之间的关系。

步法

观察步幅、速度、转身与停顿如何表现人物状态。

调度

关注演员之间的距离、方位和移动路线如何推动剧情。

入门练习：观看一段无声表演，尝试只通过眼神、手势、步法和空间关系判断人物情绪。再打开声音，比较唱腔如何补充或改变你的理解。
